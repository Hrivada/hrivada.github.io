# hrivada.github.io

Personal academic website of Héctor Rivada Rodríguez (PhD student, Universidade de Santiago de Compostela): https://hrivada.github.io

Built with [Jekyll](https://jekyllrb.com/) on GitHub Pages, using the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template (itself based on [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)), with custom styling, bilingual pages (English/Spanish) and a 3D viewer for printed pieces.

The site does not host PDFs or datasets: publications, posters and presentations are archived in Zenodo and linked from here by DOI.
